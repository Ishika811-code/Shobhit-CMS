SHOBHIT UNIVERSITY, GANGOH | COLLEGE CMS FRONTEND

Built with React, Vite, Tailwind CSS and lucide-react.

REQUIREMENTS
- Node.js 18 or newer
- npm

RUN LOCALLY
1. Extract the ZIP file.
2. Open the extracted folder in VS Code.
3. Open Terminal in that folder.
4. Run: npm instal
5. Run: npm run dev
6. Open the local URL printed by Vite, usually http://localhost:5173

BUILD
- npm run build
- npm run preview

INCLUDED
- Institutional sign-in screen based on your reference
- Password recovery screen
- Responsive Academics dashboard
- Classroom page with Active Courses, Assignments and Notes tabs
- Events page with filters and demo registration interactions
- Fees page and payment history examples
- Profile page
- Desktop sidebar and mobile bottom navigation
- Mobile navigation drawer, search toggle, notifications and profile menu
- Shobhit University logo asset at public/shobhit-logo.png
- Responsive Tailwind CSS layout and accessible focus styles

IMPORTANT
This is a frontend demonstration only. Student names, GPA, attendance, events, fees and receipts are sample data inspired by your screenshots, not verified university records. Sign-in is a demo interaction and does not authenticate anyone. Password recovery, check-in, registrations, fee payment, file downloads and profile changes need the approved backend and must not be treated as live services.

Your SRS specifies React/Vite on the frontend, Node.js/Express on the application layer, and MongoDB/Mongoose for data. It also requires role-based navigation, authorized dashboard summaries, responsive screens, and loading/empty/error states. This starter is a frontend prototype; connect it to your team's approved APIs before production. The SRS notes that payments, QR attendance, SMS/email automation and ERP integrations are out of scope unless separately approved.
